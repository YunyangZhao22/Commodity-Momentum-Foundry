## 二、华泰期货 CTA 量化策略因子系列（2017）

该系列为华泰期货量化组罗剑主导的 4 篇连续报告，统一口径：品种池为三大商品交易所 46 个品种（按 Wind 商品指数标准分 10 类）、主力合约交易、单边万分之五交易成本、多空组合等权重 / 等波动率、年化按 250 交易日折算。

### 2.1 系列（一）：波动率因子

**核心思想**：将波动率周期划分为由价格上涨带来的**正波动率周期**与价格下跌带来的**负波动率周期**（源自 Kathryn M. Kaminski，2011），考察动量策略在不同波动率区间的收益差异。

**关键发现**：
- 动量策略在正波动周期的高波动区间表现最差（平均年化 -10.60%），在负波动周期高波动区间年化仅 3.90%，累计收益的 21.26% 发生在非高波动区间。
- 结论：CTA 并非简单的"做多波动率"，动量策略收益与波动率变化的直接相关性不高，必须区分波动率的涨跌驱动方向。

**择时优化结果**（2010.1-2017.5 样本外）：

| 指标 | 原动量策略 | 波动率择时后 |
|---|---|---|
| 年化收益 | 7.88% | 5.38% |
| 最大回撤 | 9.43% | 3.58% |
| 年化标准差 | 6.54% | 3.92% |
| 收益风险比 | 1.19 | 1.37 |

收益虽小幅下降，但回撤与波动显著收窄，收益风险比提升。

### 2.2 系列（二）：动量因子

**核心思想**：动量效应分两种形式——**面板（横截面）动量**（按过去收益率排序，做多前 10%、做空后 10%）与**时间序列动量**（做多收益为正、做空收益为负）。回溯期 R 与持有期 H 各取 5/10/22/60/120/250 日，共 36 组。

**关键设定**：以 2015 年 6 月（夜盘上市）为断点，并取牛市（2015.12-2016.11）与熊市（2011.3-2012.2）分别测试。

**关键结论**：
- **夜盘效应**：夜盘上市后动量策略增强，尤其长持有期组合夏普明显提高（面板动量夜盘后最佳 R=22、H=5 夏普 1.7333）。
- **牛熊分化**：牛市动量显著为正（面板最佳 R=22、H=5 年化 29.39%、夏普 3.3739），熊市普遍负收益（面板 R=60、H=5 年化 -10.62%、夏普 -1.2512）。
- **无固定最优参数**：单一周期参数在不同时段表现不稳定，故做多周期组合。

**多周期组合**：36 组两两相关性 >0.5 的有 420 对，>0.9 的有 71 对；剔除高相关冗余后保留 10 组，样本外测试（2015.6-2017.8）年化收益从全周期等权 6.17% 提升至剔除相关等权 8.12%、等波动率 8.65%，夏普从 0.96 提升至 1.59 / 1.64。

### 2.3 系列（三）：期限结构因子

**核心思想**：期货期限结构由库存、持有成本、市场利率与便利收益（convenience yield）共同决定。用近月/主力合约价差计算**展期收益**，做多展期收益最高的一篮子合约、做空最低的一篮子，持有主力合约组合获取展期收益。

**关键结论**：
- 长持有周期优于短周期，持有 60 日 / 120 日、对冲前 30% 为最佳参数区间。
- 最优组合（60 日、30%）：年化对数收益 7.88%、最大回撤 2.67%、波动率 3.34%、**夏普 2.09**、月胜率 70.2%、周胜率 61.2%。
- **夜盘分界**：夜盘前（2010-2015.5）夏普 2.35，夜盘后（2015.6-2017.10）降至 1.44，2015 年股指限令后资金涌入高投机品种改变了商品市场结构。

### 2.4 系列（四）：因子组合与择时

**核心思想**：动量与期限结构两大因子存在收益源互补——动量表现好时（投机者追逐趋势）期限结构的展期收益暂时失效，反之亦然；因此二者可组合并可用波动率择时。

**等权组合**（2010-2017.10）：累计收益 68.25%、年化 8.97%、波动 5.86%、回撤 8.61%、夏普 1.52——简单等权优化效果一般。

**波动率择时**（核心贡献）：

| 规则 | 对应区间 |
|---|---|
| 高波动率区间 | 用期限结构策略（回避动量反转风险） |
| 低波动率区间 | 用动量策略（等待趋势启动） |
| 切换区间 | 每日 20% 仓位切换 |

| 指标 | 波动率择时组合 |
|---|---|
| 累计收益（2010-2017.10） | 87.5% |
| 年化收益 | 11.5% |
| 年化波动率 | 8.16% |
| 最大回撤 | 5.69% |
| 夏普比率 | 1.41 |
| 索提诺比率 | 2.06（下行波动 5.59%） |
| 月胜率 / 周胜率 | 65.2% / 57.2% |

波动率择时组合在 2016 商品大牛市中弥补了期限结构策略的不足，同时规避了动量策略在行情反转时的回撤。

## 三、华泰期货 CTA 策略环境分析（2024）

**基本信息**：高天越、李逸资（研究员），李光庭、黄煦然（联系人），华泰期货研究院量化组，2024-11-13。

**背景**：CTA 基金经历 2022-2023 两年震荡回撤后，2024 年净值快速修复并创新高。报告从趋势、跨期、基本面量化三类策略分析复苏原因。

**核心结论**：
1. **趋势策略表现突出**：受益于交易拥挤度下降、市场有效波动提升（主要品种平均有效波动从 2021-2023 的 0.6 附近升至 2024 的 0.93）、策略适用性修复。
2. **跨期策略表现不佳**：黑色板块期限结构季节性反常（焦煤由远月贴水转为远月升水）导致展期收益逻辑失效。
3. **基本面量化分化**：库存策略稳健并创新高（2024 夏普 1.14 略高于前两年）；基差策略因市场定价逻辑转变，夏普从 2023 年的 2.24 降至 0.33。

**因子库（多因子体系全景）**：报告给出了华泰商品多因子体系的完整因子清单，是本系列的"全景图"：

| 类型 | 因子系列 | 超额收益来源 |
|---|---|---|
| 量价因子 | Curve 因子 | 远月相对近月价格不确定性更强的风险溢价 |
| | 期限结构因子 | 展期收益大品种的风险溢价 |
| | 动量因子 | 前期价格强势品种的额外收益 |
| | 波动率因子 | 交易波动率大的品种的风险溢价 |
| | 价值因子 | 远月贴水品种供需紧张的风险溢价 |
| | 持仓因子 | 大量资金流入的风险溢价 |
| | 偏度因子 | 收益率偏度较小的风险溢价 |
| | 流动性因子 | 交易不活跃的风险溢价 |
| | 均价突破因子 | 均线向上突破的风险溢价 |
| | 宏观 Beta 因子 | 对通胀、美元指数敏感的风险溢价 |
| 基本面因子 | 库存因子 | 去库速度较快品种的额外收益 |

## 四、华泰证券：基于风险平价的 CTA 组合策略（2020）

**基本信息**：林晓明、李聪（研究员），韩晳、王佳星（联系人），华泰证券金融工程深度研究，2020-07-20。

**方法**：构建商品期货池与策略池，对每个品种用策略池全部策略回测，筛选出 10 个稳健策略（每品种最多保留一个），以**波动率倒数**作为权重构造风险平价组合。

**结果**（2013/10/18-2020/6/30）：

| 指标 | 数值 |
|---|---|
| 年化收益率 | 15.604% |
| 夏普比率 | 2.045 |
| 最大回撤 | 6.617% |

**资产配置价值**：将 CTA 风险平价组合加入股债 ETF 后，因 CTA 与股债低相关，"股债 + CTA"组合年化收益达 7% 以上、夏普高于 CTA 指数、最大回撤低于国债 ETF（不足 4%）。

**风险提示（原文要点）**：策略筛选的过拟合检验采用"打乱重排历史回测时间序列"计算，忽略路径依赖，存在过度简化风险；历史规律存在失效可能。

## 五、系列核心逻辑串讲

华泰 CTA 系列的贡献可提炼为一条清晰的逻辑链：

1. **三大基础因子**：波动率（风险度量）、动量（趋势收益）、期限结构（展期收益）构成 CTA 量化的三根支柱。
2. **波动率是"环境变量"而非独立收益源**：波动率的涨跌驱动方向（正/负周期）决定了动量策略的适用性，波动率本身更多用于择时而非单独做多。
3. **因子互补是组合的前提**：动量（追趋势）与期限结构（赚展期、回归理性）收益源天然错位，2016 大牛市 + 2017 震荡的交替印证了互补性。
4. **择时优于等权**：波动率择时组合（年化 11.5%、回撤 5.69%）显著优于简单等权（年化 8.97%、回撤 8.61%），说明"环境感知"比"静态分散"更有效。
5. **多因子体系是最终形态**：2024 报告展示的量价 + 基本面两翼 15 类因子，是三大基础因子向完整多因子体系演进的结果；而华泰证券的风险平价报告则把因子策略进一步封装为可配置的大类资产。

**对本项目的借鉴**：华泰 CTA 系列强调的"动量因子周期性显著、单一参数不稳定、需多周期组合 + 环境择时"的结论，与本因子库"短周期弱反转、中长周期显著动量、需方向感知"的发现一致；其"期限结构季节性反常会导致跨期策略失效"的案例，提示期限结构类因子需纳入升贴水结构异常的状态判断。
