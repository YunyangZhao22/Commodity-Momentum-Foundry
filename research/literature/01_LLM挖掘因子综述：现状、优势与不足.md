## 二、四篇论文逐一精读

### 2.1 FactorMAD：多智能体辩论框架（2025）

**基本信息**：Yitong Duan, Chuheng Zhang, Jian Li，*FactorMAD: A Multi-Agent Debate Framework Based on Large Language Models for Interpretable Stock Alpha Factor Mining*，ACM 第 6 届金融人工智能国际会议（ICAIF '25），2025 年 11 月，新加坡，DOI: 10.1145/3768292.3770377，9 页。

**方法**：提出由两个具有不同先验视角的 LLM 智能体进行结构化辩论的因子挖掘框架，并配套一个基于代码的因子开发流水线（generation → validation → correction → evaluation 四阶段）。

- **智能体初始化**：从已有因子库随机采样 few-shot 样例，由 LLM 抽象出高层设计原则（如数据归一化、窗口平滑），形成两个差异化视角。
- **迭代辩论**：两智能体轮流对对方的因子进行 Summary（总结）→ Critique（批评）→ Factor（改进），交替提出改进版因子。
- **代码级因子开发**：区别于传统方法受限于预定义算子集，FactorMAD 让 LLM 直接生成标准化的 Python 因子实现代码，显著提升表达力。
- **验证与纠错**：生成的代码需通过可执行性、无未来函数（no look-ahead bias）、时序平稳性、维度一致性等校验；不通过则由专门的 correction agent 迭代修复。

**实验**：中国 A 股市场 5255 只股票，2014-01-01 至 2023-12-31；样本内 2014-2021，样本外 2022-2023；基座模型 GPT-4o（2024-08-06）；标签为未来 10 个交易日的收益；每方法挖掘 100 个因子，用 LR / MLP / LightGBM 三种模型评估。对比基线：GP（遗传规划）、DSO（深度符号回归）、AlphaGen（强化学习）、CoE（链式经验推理）。

**结果**（样本外）：
- 预测指标：IC、RankIC、AUC 全面优于基线，MSE 更低。
- 投资模拟（TopK=50、持有 10 日、成本 0.3%）：CSI300 上 AR=0.063、IR=2.984、RoMaD=1.350；CSI500 上 AR=0.086、IR=3.411、RoMaD=1.341，均为各方法最优。
- 消融：多智能体辩论相较单智能体自改进，IC 随迭代轮数持续提升，且因子代码复杂度（非注释行数）更低——即辩论既提升效果又降低复杂度、缓解过拟合。

### 2.2 Automate Strategy Finding with LLM：三阶段策略发现框架（2024）

**基本信息**：Zhizhuo Kou, Holam Yu, Junyu Luo, Jingshu Peng, Xujia Li, Chengzhong Liu, Juntao Dai, Lei Chen, Sirui Han, Yike Guo，*Automate Strategy Finding with LLM in Quant Investment*，arXiv:2409.06289v4（q-fin.PM），香港科技大学 + 北京大学。开源：github.com/kouzhizhuo/Automate-Strategy-Finding-with-LLM-in-Quant-investment。

**方法**：三阶段端到端框架，不依赖人工干预完成策略发现：

1. **Seed Alpha Factory（SAF）**：用 GPT-4o 从 11 篇金融文献中抽取、分类、过滤，生成 9 大类 100 个可执行的种子 alpha（涵盖动量、均值回归、基本面等），并支持增量更新。
2. **多模态多智能体评估**：两个智能体——Confidence Score Agent（信心打分，衡量 IC 的统计可靠性）与 Risk Preference Agent（风险偏好打分）——结合文本、数值、图像、音频、视频多模态数据，配合历史回测对因子做类别均衡的筛选。
3. **动态权重优化**：3 层 MLP 对入选因子的权重做门控优化，随市场状态自适应调整。

**结果**：在中国与美国市场均有验证；上证 50（SSE50）在 2023 年 1 月至 2024 年 1 月区间实现 **53.17% 累计收益**，显著优于各基准，并在下行保护与风险调整后收益上表现突出。

### 2.3 LLM + MCTS：公式化因子搜索（2025）

**基本信息**：Yu Shi, Yitong Duan, Jian Li，*Navigating the Alpha Jungle: An LLM-Powered MCTS Framework for Formulaic Factor Mining*，arXiv:2505.11122v3（cs.AI），清华大学交叉信息研究院 + 中关村人工智能研究院。

**方法**：把因子挖掘建模为蒙特卡洛树搜索（MCTS）问题——树的每个节点是一个候选因子公式，用 UCT 准则选择待扩展节点，由 LLM 生成改进公式，回测结果作为精细的定量反馈引导搜索。

- **LLM 双重角色**：一是提出针对性的改进建议，二是把建议翻译为具体因子公式。
- **高频子树规避（frequent subtree avoidance）**：对已发现的有效因子做频繁子树挖掘，显式约束 LLM 避开最常见子结构，以提升搜索多样性与因子异质性。
- **Alpha Zoo**：满足阈值（如 IC > 0.02）的高质量因子被收集进有效因子库，最后用于组合建模。

**动机**：作者指出传统自动化公式化挖因子的两大短板——**可解释性差**（无约束数据驱动搜索产生过于复杂、晦涩的公式）与**搜索低效**（需海量候选、易过拟合、样本外泛化差）。LLM + MCTS 旨在用先验知识与树搜索同时缓解二者。

### 2.4 QuantEvolver：强化微调因子发现（2026）

**基本信息**：Lingzhe Zhang, Tong Jia, Yunpeng Zhai, Zixuan Xie, Chiming Duan, Minghua He, Philip S. Yu, Ying Li，*From Feedback Loops to Policy Updates: Reinforcement Fine-Tuning for LLM-Based Alpha Factor Discovery*，arXiv:2605.15412v1（cs.CE），2026-05-14，北京大学 + 阿里巴巴 + 南京大学 + 伊利诺伊大学芝加哥分校。开源：github.com/QuantLLM/QuantEvolver。

**问题定位**：论文直接指出此前 LLM 挖因子方法（Alpha-GPT、QuantAgent、MCTS 等）普遍依赖 **prompt 级"生成—评估—反馈"循环**，随着循环变长会出现两大缺陷：

1. **上下文爆炸与反馈漂移**（context explosion & feedback drift）：历史候选、评估结果、反馈信号反复追加进 prompt，推理成本上升、有用反馈被稀释、优化目标逐步偏离原始任务。
2. **大模型依赖与搜索停滞**（large-model dependence & search stagnation）：依赖超大 LLM，其稳定的生成偏好易产生结构相似表达式、冗余候选、探索停滞。

**方法**：QuantEvolver 以**强化微调（policy update）取代 prompt 反馈累积**——把可执行的量化评估转化为参数更新，让一个 ≤30B 的轻量 Miner LLM 通过参数学习内化历史优化经验。关键设计：

- **Oracle 构建种子池**：由 oracle LLM 生成、校验 DSL 合法性、打分、筛选出精英非冗余种子因子。
- **Regime Backtest（分域回测）**：在不同市场 regime 下评估因子。
- **DiCo Reward（多样性-互补性奖励）**：在原始预测性能基础上，叠加 novelty（新颖性）、redundancy（冗余度）、behavioral diversity（行为多样性）、complementarity（互补性）校准，鼓励生成既有效又多样、互补的因子。

**结果**：三个真实市场基准（短周期单资产方向预测、高频截面因子挖掘、日频 ETF 因子发现）上均超越现有 LLM 基线——单资产方向预测方向准确率相对提升 7.8%；高频截面上最强基线样本外 RankIC 提升 109.5%，top-10 RankIC 均值提升 186.9%。

## 三、LLM 挖因子的现状

综合四篇论文，可勾勒出 LLM 挖因子在 2023-2026 年的演进脉络：

| 阶段 | 代表工作 | 优化机制 | 反馈载体 |
|---|---|---|---|
| 交互式 | Alpha-GPT（2023）、FAMA | 人机对话生成因子 | prompt |
| 反馈驱动 | QuantAgent、AlphaAgent | 历史实验记录 + 知识反馈 | prompt 追加 |
| 搜索增强 / 智能体化 | LLM+MCTS（2505.11122）、FactorMAD、R&D-Agent | 树搜索、多智能体辩论 | 回测定量反馈 |
| 策略更新 | QuantEvolver（2605.15412） | 强化微调、参数内化 | policy 参数更新 |

**现状要点**：
1. **范式迁移**：从"把 LLM 当对话助手"演进到"把 LLM 当可微优化的生成器"，反馈从显式 prompt 累积转向隐式参数内化。
2. **基座模型分层**：主流用 GPT-4o 等超大模型，QuantEvolver 证明 ≤30B 轻量模型经强化微调也可行，降低对大模型的依赖。
3. **可解释性是共同卖点**：四篇论文都选择公式化/代码化因子而非神经网络隐因子，强调"有明确数学表达式"这一可解释性优势。
4. **实验集中在股票市场**：A 股、美股、ETF 为主，商品期货、跨资产、高频场景覆盖仍有限。

## 四、LLM 挖因子的优势

1. **自动化与规模化**：摆脱人工设计因子效率低、主观偏见限制探索空间的瓶颈，可批量生成、评估、筛选候选因子（FactorMAD 引言）。
2. **可解释性**：相对 FactorVAE、HIST、REST 等神经网络隐式因子，公式化因子具备明确表达式，便于理解经济机理、归因与实盘落地（MCTS 论文引言）。
3. **表达力与灵活性**：代码级生成（FactorMAD 的 code-based pipeline）突破遗传规划、符号回归等方法对预定义算子集的限制，能生成更复杂的因子。
4. **先验知识与推理能力**：LLM 的领域知识与推理能力适合生成"有金融逻辑支撑"的因子，而非纯数据驱动的暴力搜索。
5. **多样性机制成熟**：多智能体辩论（FactorMAD）、频繁子树规避（MCTS）、DiCo 多样性-互补奖励（QuantEvolver）等手段，使生成因子在结构与行为上更异质、更互补，减少冗余。
6. **经验可复用**：QuantEvolver 将优化经验内化进模型参数，避免每次挖掘都从零开始重复搜索。

## 五、LLM 挖因子的缺陷与不足

（以下按"被论文自身指出"与"综合评估补充"两类归纳）

### 5.1 论文自身明确指出的缺陷

1. **上下文爆炸与反馈漂移**（QuantEvolver 核心论点）：长循环反复追加历史候选与反馈，导致推理成本上升、有效信息稀释、优化目标偏离原始任务。
2. **大模型依赖与搜索停滞**（QuantEvolver）：超大 LLM 稳定生成偏好 → 结构相似表达式、冗余候选、探索停滞。
3. **可解释性差与搜索低效**（MCTS 论文）：传统自动化方法无约束数据驱动探索，产生过度复杂晦涩的公式；海量候选生成在低信噪比市场下易产生伪相关性、过拟合、样本外泛化差（Harvey-Liu-Zhu 2016 的担忧被再次引用）。
4. **单一智能体自改进效果有限**（FactorMAD 消融）：无外部批评的单智能体迭代，因子 IC 提升不明显。

### 5.2 综合评估补充的不足

1. **回测口径与实盘约束缺位**：四篇论文多以 IC / RankIC / 累计收益为纲，对交易成本（多数仅 0.3% 或未详述）、滑点、容量、换手、涨跌停/停牌等实盘约束的处理不统一，结论的实盘可迁移性存疑。
2. **数据范围局限**：集中在股票（A 股 / 美股 / ETF），商品期货（尤其国内 81 品种）、跨资产、高频、另类数据覆盖不足，难以直接迁移到本项目关注的商品期货动量因子场景。
3. **评估维度单一**：多以预测性（IC 类）为唯一优化目标，对因子经济逻辑、风险贡献、跨 regime 稳健性、与其他因子的相关性缺乏统一框架（QuantEvolver 的 DiCo 奖励是少数例外）。
4. **可复现性与公平性差**：基座模型版本、prompt 模板、回测框架、数据切分各异，跨方法横向比较困难。
5. **过拟合风险未被根本解决**：即使有辩论 / 树搜索 / 强化微调，在低信噪比 + 大规模候选生成下，"挖掘出的因子"仍可能是样本内噪声的偶然表达，样本外衰减是普遍现象（FactorMAD 样本外表现已明显弱于样本内）。

## 六、与本项目（商品期货动量因子库）的关联

1. **方法论可借鉴**：F01-F119 因子库的标准化 6 段式文档化，可引入"LLM 生成候选 → 回测定量反馈 → 去冗余"的闭环，用于因子库扩容与交叉验证。
2. **需适配商品期货特性**：本项目强调**截面 IC 与时序 IC 双口径方向可能相反**（如 F34 TRIX），而上述 LLM 论文几乎只做股票截面 IC，未覆盖单品种择时口径；直接套用会忽略商品期货的方向感知与期限结构逻辑。
3. **可解释性诉求契合**：商品期货因子库坚持"公式可计算 + 商品逻辑可解释"（Type I 因子），与 LLM 挖因子"公式化、可解释"的目标一致，LLM 可作为生成 Type I 候选因子的辅助工具。
4. **风险提示**：LLM 挖因子的过拟合与样本外衰减问题在本项目同样存在，需沿用"方向审计表 → Top-N 修复 → 统一模板"的自审机制，对 LLM 生成因子做独立回测而非直接采信。
